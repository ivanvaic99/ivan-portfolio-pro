Case Study — Product Feed Builder

CSV → Google Merchant XML (client-ready)

Open the App Back to Portfolio

Problem

  • Prodavnice imaju CSV export iz WooCommerce-a, ali je ručno pravljenje Google Merchant XML-a sporo i sklono greškama.
  • Agencijama treba brz, siguran način da premapiraju kolone (title, price, link, image…).

Rešenje

  • Frontend app (bez servera) — učitavanje CSV-a preko PapaParse.
  • UI za mapiranje kolona + autodetekcija (id/sku, title, price…).
  • Opcije: currency, VAT %, default availability/condition.
  • Generiše validan XML (RSS + g: namespace) i JSON.

Tehnologije

  • Vanilla JS + PapaParse (CSV), bez backend-a (radi na GitHub Pages).
  • Minimalan CSS dizajn (tamna tema), fokus na UX i čitljivost.
